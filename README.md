# JorgeX Pi

Pi-native runtime package for the JorgeX harness.

This development scaffold defines Pi's four native resource lists but intentionally leaves them empty. The machine-readable compatibility and ownership boundary lives under `contract/`; resources are introduced only by their dedicated roadmap PRs.

All companion packages in `contract/components.v1.json` are roadmap entries until they are independently audited and marked active. The development package does not install, activate, or bundle them.
